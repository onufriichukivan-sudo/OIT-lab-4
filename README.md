# FinTrack — Фінансовий трекер (Лабораторна робота № 4)

Вебзастосунок для обліку особистих доходів, витрат та візуалізації фінансової аналітики з підключенням до **Supabase** (PostgreSQL + Auth + RLS).

## Що реалізовано у Лабораторній роботі № 4

1. **Адаптивна верстка та медіа-запити (`styles/main.css`)**:
   - Точки переходу `1100px`, `760px`, `640px`, `480px`, підтримка `prefers-reduced-motion` та `hover: none`.
2. **Нерухома кнопка `Sign in` на малих екранах**:
   - На ширині `<= 760px` кнопка `#open-auth` зафіксована у правому нижньому куті (`position: fixed; right: 20px; bottom: 24px; z-index: 105`) і відкриває модальне вікно автентифікації `<dialog id="auth-modal">`.
3. **Адаптивне бургер-меню (`#mobile-menu-toggle`)**:
   - На мобільних пристроях з'являється верхня панель з анімованою кнопкою меню, виїзним сайдбаром, затемненням фону (`#nav-backdrop`) та підтримкою клавіші `Escape`.
4. **Плавний перехід кнопки «Нагору» (`#scroll-up`)**:
   - Плавна поява (`opacity` + `transform` з `cubic-bezier`) та плавна прокрутка до початку сторінки.
5. **Карусель відгуків користувачів (`#reviews-carousel`)**:
   - У секції зворотного зв'язку `#feedback` реалізовано інтерактивну карусель відгуків із кнопками навігації, індикаторами-крапками, автопрокруткою (з паузою при наведенні), свайпами та миттєвим додаванням нового відгуку з форми.
6. **Анімації та перемикач темної/світлої теми**:
   - Плавна поява карток показників (`@keyframes cardReveal`), анімація модальних вікон (`@keyframes dialogPop`), hover-ефекти та збереження обраної теми у `localStorage`.
7. **Bootstrap 5 (`pages/article-1.html`)**:
   - Сторінка «Як почати вести бюджет» створена на основі шаблонів і компонентів **Bootstrap 5.3.3** (Navbar, Breadcrumb, Grid Cards, інтерактивний калькулятор бюджету, Progress Bars, Accordion).
8. **Препроцесор Sass / SCSS (`styles/article-sass.scss` → `styles/article-sass.css`)**:
   - Сторінка `pages/article-2.html` («Правило 50/30/20») стилізована за допомогою Sass (змінні `$`, міксини `@mixin`, `@extend`, цикл `@each`, вкладеність). Для перекомпільовування у VS Code використовується розширення **Live Sass Compiler**.
9. **Додаткове завдання 1\* — Валідація форм засобами HTML і CSS**:
   - Форми входу та реєстрації (`#login-form`, `#register-form`) використовують атрибути (`required`, `type="email"`, `minlength`, `pattern`, `placeholder=" "`) та псевдокласи (`:valid`, `:invalid`, `:placeholder-shown`, `:has()`) без участі JavaScript.
10. **Додаткове завдання 2\* — Запрошення на подію та конверт (`pages/invitation.html`)**:
    - Інтерактивний конверт із сургучною печаткою, персоналізація імені гостя, офіційне запрошення та кнопка друку (`window.print()`) зі стилями `@media print`.
