# Де в проєкті використано Flexbox і Grid

**Flexbox** (одномірна система: ряд або стовпець) застосовано там, де елементи йдуть в одну лінію й потрібне вирівнювання.
**Grid** (двовимірна система: рядки й стовпці одночасно) застосовано там, де потрібна сітка.

## Grid

| Місце | Селектор | Навіщо |
|---|---|---|
| Каркас застосунку | `.shell` | Два стовпці: сайдбар `220px` і основна частина `1fr` |
| Картки показників + графік | `.stats-grid` | 3 стовпці карток і широка картка графіка справа (`grid-row: 1 / 3`) |
| Пари панелей (категорії, рейтинги) | `.two-col` | Дві рівні колонки, на телефоні одна |
| Картки порад | `.tip-list` | `repeat(auto-fit, minmax(210px, 1fr))`: кількість колонок підбирається сама |
| Рядок транзакції | `.tx-row` | Колонки: іконка, назва, категорія, сума, кнопка видалення |
| Форма додавання транзакції | `.tx-form` | Шість полів в один ряд, на планшеті по два |
| Категорії з прогрес-барами | `.topic-list li` | Іконка на два рядки зліва, назва й смуга по центру, відсоток справа |

## Flexbox

| Місце | Селектор | Навіщо |
|---|---|---|
| Шапка сторінки | `.main-header`, `.main-header-actions` | Заголовок ліворуч, пошук і кнопки праворуч |
| Меню в сайдбарі | `.sidebar ul`, `.sidebar a` | Вертикальний список; іконка й текст в один ряд |
| Фільтри | `.filters` | Ряд із переносом на вузьких екранах |
| Заголовок картки графіка | `.chart-card-head` | Назва ліворуч, вибір періоду праворуч |
| Картка поради | `.tip-card`, `.tip-body` | Стовпець, посилання «Читати далі» притиснуте донизу |
| Заголовок на зображенні | `.tip-title` | Центрування тексту по вертикалі й горизонталі |
| Налаштування | `.settings-row` | Підпис ліворуч, значення праворуч |

## Позиціювання (лаб. 3)

| Елемент | Властивості |
|---|---|
| Підменю | `li.has-submenu { position: relative }`, `.submenu { position: absolute }` |
| Кнопка «до навігації» | `position: fixed; left: 24px; bottom: 24px; z-index: 100` |
| Текст на картці поради | `.tip-title { position: absolute; inset: 0 }` поверх зображення |
| Лупа в пошуку | `.search-btn { position: absolute; right: 5px }` всередині `.search-input-wrap { position: relative }` |

## Адаптивність

Перевірено в DevTools (Ctrl+Shift+M) на ширинах 1280, 768 і 390 px. Точки переходу: `960px`, `760px`, `600px`, `480px`.
